## Goals & Non-Goals

### Goals

1. 已解锁时导航可见 **Lock**；点后 cookie 失效，再进 dashboard 只有解锁表单。
2. `DELETE /api/auth/editor-session` 幂等清 cookie（无 cookie 也 204/200）。
3. 解锁成功清除该连接的失败计数，避免「4 次错 + 1 次对 + 1 次错」误 429。
4. 根语言 `zh-CN`；公开首页英文营销区标 `lang="en"`。
5. 知识点/标签勾选、加篮/移除、taxonomy 删除/改父、主导航链接：可点区域 **min-h-11**（44px）。
6. `:focus-visible` 全局 2px 环；去掉搜索框 `outline-none`。
7. 解锁失败：`aria-invalid` + `aria-describedby` 指向 `#unlock-error`。
8. README Secrets 收录 `TRUST_PROXY`；development.md 写明非生产 `X-Physhub-Editor-Session`；Playwright 注释改为 build 缺失 / 用系统 Chrome。

### Non-Goals

- cookie `maxAge`、导航中文文案、窄屏汉堡菜单（E2）。
- 正式题 Save 无 KP 禁用（E2，不挡 a11y 7）。
- 会话表、多用户、多实例限流。
- 全站 i18n 框架、axe 流水线、暗色主题。
- 改 schema / agent 工具。

## Proposed Design

### E1-A — 登出与限流复位

**DELETE `/api/auth/editor-session`**

- 不要求已登录（幂等）。agent Bearer 打这条 → 与其它 human 路由一样 403（`requireHumanApiAuth`，非 publishRoute），避免用 agent key 当「清 cookie」工具；无 cookie 的人可以 DELETE。
- 矛盾：无 cookie 的人要清残留 cookie，不能先 `requireHumanApiAuth`（会 401）。

**选定：** DELETE **不走** `requireHumanApiAuth`。只做：

```ts
response.cookies.set({
  name: EDITOR_SESSION_COOKIE_NAME,
  value: "",
  httpOnly: true,
  sameSite: "lax",
  path: "/",
  maxAge: 0,
  secure: process.env.NODE_ENV === "production",
});
return NextResponse.json({ ok: true });
```

Agent 清浏览器 cookie 无意义（agent 不用 cookie）。不给 agent 特殊 403。

**Lock 按钮**

- 抽 `components/auth/lock-button.tsx`（client）：`fetch DELETE` + `credentials: "include"` + `location.assign("/")` 或 `reload`。
- **选定：成功后 `location.assign("/")`**，避免停在仍显示解锁表单的 dashboard 中间态。
- `Nav` 增加可选 `unlocked?: boolean`。仅 `true` 时渲染 Lock。
- `app/layout.tsx`：`const session = await readEditorSessionFromCookies()`，`<Nav unlocked={Boolean(session)} />`。整站变动态可接受（dashboard 已 `force-dynamic`）。

**限流**

```ts
export function recordEditorUnlockSuccess(request: Request): void {
  unlockFailures.delete(getConnectingIp(request));
}
```

POST 解锁成功、`Set-Cookie` 之前调用。单测：同一测试 IP 失败 4 次 → 成功 → 再失败 1 次仍 401 而非 429。

### E1-B — 语言、触控、焦点、解锁绑定

**语言**

- `layout.tsx`：`<html lang="zh-CN">`
- `app/page.tsx`：外层 `<main lang="en">`（首页英文不动）
- dashboard 页不标 lang，继承 zh-CN。导航仍英文（E2 再译，避免一次改光所有 getByRole name）

**44px 行**

统一 class：`flex min-h-11 cursor-pointer items-center gap-3 px-2`

- `taxonomy-fields.tsx` 知识点/标签 `<label>`
- `question-list.tsx` / `question-search-panel.tsx` Add to basket
- `question-set-basket.tsx` Remove
- `taxonomy-admin.tsx` Save parent / Delete
- `nav.tsx` 每个 `Link`：`inline-flex min-h-11 items-center px-2`；`ul` 允许 `flex-wrap`

checkbox 本身可保持 `size-4`，扩大的是整行 label。

**焦点**

`globals.css`：

```css
:focus-visible {
  outline: 2px solid #b35a2f;
  outline-offset: 2px;
}
```

删除搜索 input 的 `outline-none`，保留 `focus:border-orange-800` 作为附加。

**解锁表单**

```tsx
<input
  id="editor-secret"
  aria-invalid={error ? true : undefined}
  aria-describedby={error ? "unlock-error" : undefined}
/>
{error ? (
  <p id="unlock-error" role="alert">{error}</p>
) : null}
```

E2E `unlock.spec.ts` 继续用 `getByText("Unauthorized")`，不要 `getByRole("alert")` 以免撞 Next 播报器。

### E1-C — 文档

README Secrets 表增加一行：

| `TRUST_PROXY` | 反代 | 默认未设。v1 按**单实例**部署。未设时解锁限流把所有人算进 `"local"` 一个桶。只在可信反代后设 `true`。 |

development.md：

- 非生产可用请求头 `X-Physhub-Editor-Session`（值 = HMAC hex，与 cookie 相同）；生产忽略。
- 登出：已解锁导航 Lock，或 `DELETE /api/auth/editor-session`。
- E2E：Playwright 1.60 若缺 `chromium_headless_shell-1223`，用 `PLAYWRIGHT_CHROME_CHANNEL=chrome`；不是「Ubuntu 26.04 不能装 Chromium」。

`playwright.config.ts` 注释改成与上面同一句话。

`.env.example` TRUST_PROXY 注释补一句单实例假设。

## Alternatives

1. **登出也要 session** — 否决。过期/损坏 cookie 无法自助清。
2. **Lock 始终显示** — 否决。未解锁首页多一个无意义按钮。
3. **cookie maxAge 12h 放进 E1** — 推迟 E2。会话 cookie + 显式 Lock 已够 7 分。
4. **导航改中文放进 E1** — 推迟 E2。会改一串测试 name，和触控/语言声明解耦。
5. **TRUST_PROXY 默认 true** — 否决。伪造 X-Forwarded-For 可绕过限流。

---

## Security

- DELETE 公开且幂等：最坏是登出自己，不能提升权限。
- 不新增读答案路径。layout 读 cookie 只为显示 Lock，不把 draft 字段送进 Nav。
- Agent 仍不能 promote。
- 不把 `EDITOR_SESSION_SECRET` 送进客户端。Lock 只打 DELETE。

## Risks

| 风险 | 缓解 |
| --- | --- |
| layout 读 cookie 让首页也动态 | 可接受；本产品无静态营销 CDN 需求 |
| min-h-11 让 taxonomy 树变长 | 用整行点击换高度，不改树算法 |
| 中文 lang + 英文 nav | 声明语言对老师校验；英文链仍可读。E2 再译 |
| push 被当成代码完成 | 方案把 push 单列为发布动作，合代码之后做 |

---

## Key Decisions

1. **E1 只拉到 7/7，不追求 9。**
2. **DELETE 无认证、幂等清 cookie。**
3. **Lock 仅在有效会话时出现；成功后回首页。**
4. **成功解锁清除该 IP 失败桶。**
5. **限流算法不改；用文档固定单实例 + 可选 TRUST_PROXY。**
6. **html zh-CN；首页 main 英文。**
7. **44px 做在 label/链接上，不放大原生 checkbox 外观。**
8. **不改导航文案、不上 cookie maxAge（E2）。**
